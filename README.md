# FoodWise – Food Waste Reduction in Households

- User Registration/Login
- User-wise data separation
- Food Inventory
- Expiry Tracking
- Meal Planning
- Waste Logging
- Waste Analysis
- Food Saving Tips
- Installable PWA

- Flask
- SQLAlchemy
- SQLite
- Bootstrap 5
- JavaScript
- PWA

PythonAnywhere
